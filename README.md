# 🎯 Student Skill Gap Analyzer

An AI-powered web application that analyzes a student's current technical skills, identifies skill gaps, and generates a personalized learning roadmap based on their target career.

## 🚀 Features

- 👤 Student profile and career selection
- 📊 Technical skill self-assessment
- 📝 Career-specific technical quiz
- 🤖 AI-powered skill gap analysis
- 📈 Career readiness score
- 🎯 Identification of strong and weak skills
- 🗺️ Personalized learning roadmap
- 💡 Recommended learning resources

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- AI API
- Jinja2
- Git & GitHub
